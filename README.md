# Noufanudheen's Portfolio

Welcome to my personal portfolio. Built because sending a plain PDF resume felt way too boring.

### Key Details

- **Frosted Glass Cards**: Sleek glassmorphic UI designed with custom CSS backdrop filters and specular highlights.
- **Chillin' 3D Cube**: A floating 3D cube in the background that only spins when you move your mouse or swipe your screen.
- **Shy Stars**: Background stars that jump half a centimeter away whenever your cursor or finger gets close.
- **Mobile Ready**: Clean, distraction-free navigation tailored specifically for phone viewports.
